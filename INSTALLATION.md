# 🎮 Squart - Installation Instructions for macOS

Welcome to Squart! Follow these simple steps to install and run the game on your Mac.

## 📥 Installation Steps

### Step 1: Download
Download the `Squart-macOS-v1.0.dmg` file.

### Step 2: Open DMG
Double-click the downloaded `.dmg` file to open it.

### Step 3: Install (Optional)
You can either:
- **Option A:** Drag `squart.app` to your Applications folder
- **Option B:** Run directly from the DMG (double-click squart.app)

### Step 4: First Launch (Important! ⚠️)

**macOS will show a security warning because the app is not signed with an Apple Developer certificate.**

#### How to bypass this security warning:

1. **Right-click** (or Control+click) on `squart.app`
2. Select **"Open"** from the menu
3. A dialog will appear saying the app is from an unidentified developer
4. Click **"Open"** in the dialog

**That's it!** After the first time, you can launch the app normally by double-clicking.

---

## 🎯 Why this security warning?

The app is not signed with an Apple Developer certificate (which costs $99/year). This is normal for indie/test applications. The app is completely safe to run - it's just a game!

## 🎮 How to Play

Once the app is running:

1. Click the **❓ (How to Play)** icon in the top-right corner for a tutorial
2. Choose your game settings:
   - **Board size:** 5×5 to 20×20
   - **Timer:** Unlimited or timed games
   - **Game mode:** Player vs Player or Player vs AI
3. Click **"Start Game"** and enjoy!

## 🐛 Troubleshooting

### "The app is damaged and can't be opened"

This can happen if the download was corrupted or if Gatekeeper is being extra strict:

```bash
# Open Terminal and run:
xattr -cr /path/to/squart.app

# Then try opening again with right-click → Open
```

### App won't open at all

Make sure you're on:
- **macOS 11 (Big Sur) or newer**
- **Apple Silicon (M1/M2/M3) or Intel Mac**
